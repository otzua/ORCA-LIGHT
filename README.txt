========================================================================
ORCA-LIGHT - Ultra-Lightweight Native Windows Launcher
========================================================================

IMPORTANT:
Always extract the ZIP file first before running any files!
Right-click "Orca-Light-Windows-x64.zip" -> "Extract All...".

TWO WAYS TO RUN:
1. Quick Test (No Install):
   Double-click "run.bat" to start Orca-Light immediately in portable mode.

2. Full Installation:
   Double-click "install.bat" to install to %LOCALAPPDATA%\Orca-Light,
   create a Start Menu shortcut, and enable Windows auto-start on boot.

HOW TO USE:
- Press [Windows Key + Space] or [Ctrl + Space] anytime to toggle Orca-Light.
- Type to search apps, files, math, system commands, or clipboard history.

KEYBOARD SHORTCUTS:
- Windows Key + Space : Open or hide Orca-Light (primary)
- Ctrl + Space         : Open or hide Orca-Light (secondary fallback)
- Enter               : Launch app / Open file / Execute command
- Ctrl + Enter        : Open containing folder in File Explorer
- Ctrl + Shift + Enter: Run as Administrator
- Ctrl + Shift + C    : Copy path to clipboard
- Up / Down Arrows    : Navigate results
- Page Up / Page Down : Jump 5 items
- Esc                 : Clear search / Close window

FEATURES:
- Instant App Launcher: Searches Start Menu, Program Files, and System tools
- Fast File Search    : Searches your Desktop, Documents, Downloads, etc.
- Instant Calculator  : Type any math (e.g. 128 * 4, sqrt(256), sin(pi/2))
- System Commands     : Type > shutdown, > restart, > lock, > sleep,
                        > empty recycle bin, > task manager, > settings, > exit
- Clipboard History   : Type cb or @clip to search recent clipboard items

TROUBLESHOOTING:
- If Orca-Light does not appear, check the diagnostic log located at:
  %LOCALAPPDATA%\Orca-Light\orca-light.log
- Both Win + Space and Ctrl + Space are active. Try pressing Ctrl + Space if
  another app holds Win + Space.

HOW TO UNINSTALL:
- Double-click "uninstall.bat" to completely remove Orca-Light and autostart.
